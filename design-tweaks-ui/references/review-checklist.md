# Design Tweaks — 候補比較レビュー

候補ごとに同じ画面・同じデータでレビューする。パネルで候補を切替えながらチェック。

## 比較記録テンプレート

```markdown
## 候補: [label] (`[id]`)

### 所感（1–2 文）


### チェック
- [ ] 375px — 横スクロールなし
- [ ] 768px — 主要情報が above the fold
- [ ] 1280px — 余白バランス OK
- [ ] 本文コントラスト AA（4.5:1）
- [ ] CTA が primary 色で一貫
- [ ] 主要タスク 3 クリック以内

### 問題点


### スコア（任意 1–5）
- 可読性:
- ブランド適合:
- 実装コスト:
```

## 深刻度

| 級 | 意味 | 例 |
|----|------|-----|
| **ブロッカー** | 採用不可 | コントラスト NG、タップ領域 < 44px |
| **警告** | 条件付き採用 | 1280px のみ余白過多 |
| **メモ** | 任意 | アニメーション好み |

## 採用決定

```markdown
## 決定
- **採用候補**: `[id]`
- **理由**:
- **昇格タスク**:
  - [ ] vars → tailwind.config / :root
  - [ ] 未 token 化のハードコード色を洗い出し
  - [ ] Tweaks dev flag 確認
```
