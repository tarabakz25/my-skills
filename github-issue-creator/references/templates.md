# GitHub Issue Templates

## Bug Report Template

```markdown
## 概要
<!-- バグの簡潔な説明 -->

## 再現手順
1.
2.
3.

## 期待する動作
<!-- 本来どうなるべきか -->

## 実際の動作
<!-- 実際に何が起きているか -->

## 環境
- OS:
- ブラウザ/ランタイム:
- バージョン:

## スクリーンショット・ログ
<!-- 任意: エラーメッセージ、スクリーンショット等 -->

## 補足
<!-- その他関連情報 -->
```

## Feature Request Template

```markdown
## 概要
<!-- 提案する機能の簡潔な説明 -->

## 背景・モチベーション
<!-- なぜこの機能が必要か、どんな問題を解決するか -->

## 提案する解決策
<!-- 機能の詳細な説明 -->

## 代替案
<!-- 検討した他のアプローチ -->

## 実装上の考慮事項
<!-- 技術的な注意点、依存関係、影響範囲 -->

## 補足
<!-- モックアップ、参考リンク等 -->
```

## Labels Reference

### Type Labels
- `bug` - 不具合・バグ
- `enhancement` - 機能改善・新機能
- `documentation` - ドキュメント
- `question` - 質問・調査
- `refactor` - リファクタリング

### Priority Labels
- `priority: high` - 優先度高
- `priority: medium` - 優先度中
- `priority: low` - 優先度低

### Status Labels
- `needs-triage` - トリアージ待ち
- `in-progress` - 対応中
- `help wanted` - 助けが必要

### Size Labels
- `size: small` - 小規模 (数時間)
- `size: medium` - 中規模 (数日)
- `size: large` - 大規模 (1週間以上)
